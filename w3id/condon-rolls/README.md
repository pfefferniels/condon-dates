# condon-rolls

The red Welte rolls of the Condon collection at Stanford Libraries as linked data: when
each copy was punched, the hand that signed it and how the perforator was set, read off
the scans, in the format of linked-rolls.

- Homepage: https://pfefferniels.github.io/condon-dates/
- Source: https://github.com/pfefferniels/condon-dates
