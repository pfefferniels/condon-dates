# welte-hands

The hands that signed Welte piano rolls, as authority records for editions to name:
persons known by a signature rather than identified, at present on the red Welte rolls of
the Condon collection at Stanford Libraries, in the format of linked-rolls. Everything
else about the rolls that has an authority record is named by the GND.
