# welte-premises

Premises for dating Welte piano rolls: what measuring the rolls of a collection, at
present the red Welte rolls of the Condon collection at Stanford Libraries, allows an
edition to conclude about one of them. Each premise is a belief with the evidence it rests
on, in the format of linked-rolls.
